매물 호가 트래킹

아파트 시세 트래킹

네이버 부동산에서 단지 매물 목록을 복사해 붙여넣으면 자동으로 파싱해 4층 이상 최저 호가(저층뿐이면 저층 표기)와 매물 수를 기록하고, 시점별 변화를 그래프로 보여줍니다. 데이터는 이 브라우저(로컬)에 저장됩니다.  ·  ← 세제개편 계산기로

관심 단지

단지를 클릭하면 아래에서 매물 붙여넣기·그래프를 볼 수 있습니다. 같은 단지라도 평형별로 따로 등록하세요.

아직 등록된 단지가 없습니다. 위에서 단지명과 평형을 추가하세요.

매물 기록

네이버 부동산(land.naver.com)에서 이 단지·평형의 매물 목록 텍스트를 드래그 복사해서 붙여넣으세요. 매매·전세가 섞여 있어도 자동 분류됩니다.

매물이 없을 때는 국토부 실거래가 공개시스템(rt.molit.go.kr)에서 최근 3개월 거래를 확인해 평균을 입력하세요. "실거래" 배지로 구분 저장됩니다.

파싱 규칙 · 정확하게 가져오는 법 (개발자도구 JSON)
  • 가격: "매매 44억", "전세 12억 5,000", "44억5,000" 형식 인식 (월세는 제외)
  • 층: "12/28층" 숫자층 또는 "저/중/고" 표기 인식 — 4층 이상 또는 중·고층 매물 중 최저가를 대표 호가로 기록
  • 4층 이상 매물이 없고 저층(1~3층·"저")만 있으면 저층 최저가를 쓰고 저층 배지를 붙입니다
  • 미리보기에서 잘못 인식된 줄은 체크 해제로 제외할 수 있습니다
더 정확한 방법 (PC 크롬):
  1. 네이버 부동산에서 단지 매물 목록을 연 상태에서 F12 → Network 탭 열기
  2. 필터에 articles 입력 후 매물 목록을 새로고침(또는 스크롤)
  3. articles?complexNo=… 요청 클릭 → Response 탭 내용 전체 복사(Ctrl+A, Ctrl+C)
  4. 위 입력창에 붙여넣고 파싱하기 — JSON을 자동 인식해 층·가격을 정확히 읽습니다
